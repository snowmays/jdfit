# JDfit · 简历岗位优化助手

一个 Claude Code Skill：智能分析 JD（职位描述）与简历的匹配度，直接在原 DOCX 上优化内容，并用 **Word 原生批注**详细说明每处修改的原因和优化逻辑。

## 功能特点

- **五维度评分**：JD 匹配度（40 分）、量化成果（25 分）、结构逻辑（15 分）、语言专业度（10 分）、ATS 友好度（10 分），满分 100
- **智能优化**：STAR 结构化表达、强动词替换、量化成果补充、关键词自然融入、删除无效信息
- **Word 原生批注**：每处修改位置都有批注气泡，包含修改类型、原文、优化后内容、优化逻辑、匹配度提升评估
- **关键信息提醒**：发现简历中缺少 JD 核心要求的重要信息时，会提醒你补充，而非胡编乱造
- **格式保留**：在原始 DOCX 上直接修改，保留原有排版和样式
- **双文件输出**：同时保存原始简历备份 + 带批注的优化版

## 批注示例

用 Word 打开优化后的简历，右侧边栏会显示类似这样的批注：

```
━━━━━━━━━━━━━━━━━━
✏️ 优化说明
━━━━━━━━━━━━━━━━━━
【修改类型】🔑 关键词优化 + 📊 量化成果

【原文】
负责电商平台后端开发

【修改后】
主导电商平台支付模块重构，优化数据库查询性能，
使订单处理速度提升 65%，支撑日均 10 万笔交易

【优化逻辑】
• 添加"主导" → 体现 ownership（JD 要求独立负责模块）
• 明确"支付模块" → 匹配 JD 核心业务
• 量化"65%"、"10 万笔" → JD 强调数据驱动思维

【匹配度提升】★★★★☆ (60% → 85%)
━━━━━━━━━━━━━━━━━━
```

## 批注类型标识

| 图标 | 类型 | 说明 |
|------|------|------|
| 🔑 | 关键词优化 | 添加/调整 JD 关键词 |
| 📊 | 量化成果 | 添加数据、百分比 |
| 🎯 | 技能匹配 | 突出相关技能 |
| ✨ | 措辞优化 | 使用更专业/有力的表达 |
| 📐 | 结构调整 | 重组内容顺序 |
| 🤖 | ATS 优化 | 针对简历筛选系统 |
| ⚠️ | 推测内容 | AI 合理推测的数据，请核实 |

## 工作流程

```
1. 提供 JD（文本 / PDF / 链接）
2. 上传简历（DOCX 格式）
3. AI 深度分析，输出五维度诊断报告
4. 如有关键信息缺失，提醒你补充
5. 生成优化简历（Word 批注说明每处修改）
6. 输出：原始备份 + 优化版
```

## 安装方法

1. Clone 本仓库到 Claude Code 的 skills 目录：

   ```bash
   git clone https://github.com/snowmays/jdfit.git ~/.claude/skills/jdfit
   ```

2. 安装 Python 依赖：

   ```bash
   pip3 install -r ~/.claude/skills/jdfit/scripts/requirements.txt
   ```

或者，将本仓库下载后整个文件夹拖入 Claude Code 对话框，然后说：

```
帮我安装这个 JDfit skill，并安装所需的 Python 依赖
```

## 使用方法

安装完成后，在 Claude Code 中说：

```
帮我对 JD 优化简历
```

或直接调用：

```
/jdfit
```

然后按提示上传 JD 和简历即可。

## 投递前检查清单

拿到优化后的简历后：

1. 用 Word 打开，查看右侧批注
2. 逐条审阅，调整不满意的部分
3. 重点检查标注 ⚠️【推测】的内容，确保数据准确
4. 确认无误后：审阅 → 删除 → 删除文档中的所有批注
5. 另存为最终版本投递

## 系统要求

- Claude Code
- Python 3.7+
- `python-docx`（见 `scripts/requirements.txt`）
